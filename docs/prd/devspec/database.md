# 개발사양 — 데이터베이스 지침

AccountInterlockHub의 데이터베이스 고정값이다. spec·build·qa가 단일 출처로 참조한다. 방향 근거는 [`../PRD.md`](../PRD.md) §시스템 제약사항.

## 데이터베이스

- **PostgreSQL 16**을 사용한다.
	- 운영: Azure의 PostgreSQL 서비스(Azure Database for PostgreSQL).
	- 개발·로컬: 별도로 구축한 PostgreSQL 서버.

## 데이터 원칙

- 허브는 **사용자 정보를 지속 보관하지 않는다**. 발송처가 전달한 암호값(encX/encY)과 복호화한 원문(X)은 **연동 실행 시점에 메모리 상에서만** 다루고 전달 후 폐기한다 — 어느 것도 저장하지 않는다.
- **연동 구성은 데이터베이스에 두지 않는다**. 진입 경로·수신처(B) 전달 주소·동의 항목·보관 기간은 배포 시점 상수이며 단일 출처는 [`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §연동 구성 상수다.
- 저장 대상은 **연동 추적 레코드 하나**로 한정한다. 연동 1건이 레코드 1건에 대응한다. 이 원칙에 예외를 두는 저장(보안 이벤트 기록·동의 증적·운영 지표 집계)은 담당자 확정 대기 항목이며, 확정 전에는 두지 않는다([`../PRD.md`](../PRD.md) §미결·확인 필요).
- 연동 추적 키는 전달 데이터(X) 내부의 지정 필드값으로, 발송처와 수신처가 공유하는 조회·통지 기준이다(불투명 문자열, 개인정보 원문 아님).

## 연동 추적 레코드

**연동 추적 키** 기준으로 사용자 진입부터 수신처(B) 완료 콜백까지를 **한 레코드**에 기록한다. 처리상태 확인·연동 완료 확인 API([`external-apis.md`](external-apis.md))의 근거 데이터이며, 사용자 정보·복호화 원문은 포함하지 않는다.

- **생성 시점** — 사용자가 진입 경로로 들어와 연동 요청이 허브에 인지된 시점에 레코드를 만든다. 허브는 그 전의 연동 요청을 알 수 없으므로, **조회 시 레코드가 없다는 것은 해당 추적 키로 진입한 사용자가 없었다는 뜻**이다.
- **갱신** — 승인·거부, 복호화 결과, 수신처 전달 결과, 결과 확인, 완료 콜백을 같은 레코드에 이어 기록한다.

기록 항목은 다음 범위다.

- 연동 추적 키
- 처리 성공 여부 · **결과 구분** · 처리 일시
- 결과 확인 여부 · 결과 확인 일시
- 수신처 완료 콜백 수신 여부 · 콜백 일시

- **결과 구분**은 발송처가 후속 조치를 판단할 수 있도록 최소한 사용자 거부·복호화 실패·수신처 전달 실패를 서로 구별한다. 구분 값 목록은 spec 단계에서 확정한다.
- **결과 확인**의 의미(발송처가 처리상태 확인 API로 결과를 받아 간 것)는 [`external-apis.md`](external-apis.md) §처리상태 확인 API가 정의한다.
- 구체 컬럼·타입·인덱스·키 설계는 spec 단계에서 확정한다.
- 추적 키의 유일성 책임과 같은 키가 다시 들어왔을 때의 동작은 담당자 확정 대기다([`../PRD.md`](../PRD.md) §미결·확인 필요).

## 보관 정책

- **일 단위 배치 작업**으로 보관 기간이 지난 추적 레코드를 삭제한다([`../ia/IA.md`](../ia/IA.md) `BAT-02`).
- 삭제 기준은 둘이며, 둘 중 **먼저 도달한 쪽**에서 삭제한다. 두 값 모두 상수로 고정한다([`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §연동 구성 상수).
	1. **결과 확인 완료 기산** — 결과 확인이 완료된 뒤 `<RETENTION_MONTHS>`(기본 3개월)이 지난 레코드.
	2. **생성 기산 절대 상한** — 결과 확인 여부와 무관하게 생성 후 `<RETENTION_MAX_MONTHS>`(기본 6개월)이 지난 레코드. 발송처가 조회하지 않은 레코드가 영구히 남는 것을 막는다.
- 배치는 애플리케이션(NestJS 스케줄 작업)에 포함된다([`infra.md`](infra.md) §애플리케이션 구성).
