# 개발사양 — 설치·배포·인프라

AccountInterlockHub의 인프라·배포 고정값이다. spec·build·qa가 단일 출처로 참조한다. 방향 근거는 [`../PRD.md`](../PRD.md) §시스템 제약사항. 용어는 [`wiki/WIKI.md`](../../../wiki/WIKI.md).

## 애플리케이션 구성

- 하나의 애플리케이션 안에 **사용자 웹·백엔드 API·보관 배치**가 함께 구성된다(논리 프로그램 3종, 배포 단위 1개).
- 프런트엔드(ReactJS, TypeScript)는 정적 빌드 산출물로 만들어지고, 백엔드(NestJS, TypeScript)가 이 산출물을 **정적 콘텐츠로 서빙**한다.
- **연동 라이브러리**는 이 애플리케이션에 포함되지 않는 **별도 배포 단위**다(§연동 라이브러리 배포).

## 배포 형태

- 운영 환경은 **하나의 Azure App Service**로 배포한다. 별도의 프런트엔드 호스팅을 두지 않는다(NestJS가 API와 정적 화면을 함께 제공).
- 구체 App Service 이름·리소스 그룹 등 배포 대상 식별자는 build/배포 준비 시점에 확정하고 [`../../../CLAUDE.env.md`](../../../CLAUDE.env.md)에 변수로 추가한다.

## 환경 구분

1. **운영(prod)** — Azure App Service + Azure의 PostgreSQL 서비스(Azure Database for PostgreSQL).
2. **테스트(test)** — 구성 항목 미정([`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §경로·제품 명칭 변수).
3. **개발·로컬(dev/local)** — 별도로 구축한 PostgreSQL 서버를 사용한다(Azure 미사용). 애플리케이션은 로컬에서 기동한다.

- 환경별 접속 정보(연결 문자열 등 비밀 값)는 커밋하지 않으며, 비밀 관리 방식은 build 단계에서 확정한다.

## 연동 구성 상수 주입

- 연동 구성 값은 **배포 시점 상수**다. 단일 출처는 [`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §연동 구성 상수이며(값 목록은 그 절이 유일한 열거처다), 배포 시 애플리케이션 설정 값으로 주입한다. 발송처가 라이브러리 호출 인자로 넘기는 값은 주입 대상이 아니다(같은 절의 별도 표).
- 값 변경은 **재배포**로만 반영된다. 런타임에 값을 바꾸는 수단(관리자 화면·구성 API)을 두지 않는다.
- 애플리케이션은 기동 시 필수 상수의 존재·형식을 확인하고, 충족하지 않으면 기동을 중단한다(누락 구성으로 서비스가 잘못 동작하지 않게 한다).
- 미확정 상수에는 실제 값과 같은 **형식의 잠정값**이 채워져 있다(같은 절의 `(**잠정**)` 표기). 형식 검증은 통과하므로 개발·검증 환경 기동을 막지 않지만, **운영 배포 전에 실제 값으로 교체**한다. 잠정값 여부는 애플리케이션이 판별하지 않으므로 배포 절차의 확인 항목으로 둔다.

## 연동 라이브러리 배포

- 연동 라이브러리는 **C#(.NET Framework 4.8) 클래스 라이브러리**다. 빌드 산출물(라이브러리 파일)과 동봉 산출물을 묶은 **배포 패키지**를 발송처에 파일로 전달한다([`external-apis.md`](external-apis.md) §연동 라이브러리). 허브 App Service 배포와 주기·경로가 분리된다.
- 빌드는 **MSBuild**(Visual Studio Build Tools)로 수행한다. 허브 애플리케이션(Node.js·TypeScript)과 빌드 툴체인이 다르므로 라이브러리 빌드 환경을 별도로 갖춘다. 빌드 PC 준비 여부는 build 착수 시점에 점검한다.
- 소스 위치·산출물명·대상 런타임은 [`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §연동 라이브러리 식별자가 단일 출처다.
- 라이브러리와 허브는 같은 암호화 규약을 구현하므로, 규약이 바뀌면 **양쪽을 함께 배포**해야 한다.
- 배포 전달 경로(발송처에 파일을 전달하는 수단)는 build 단계에서 확정한다.

## 접근 제어

- 외부에 노출되는 표면은 **사용자 진입 경로**와 **서버 대면 API**뿐이다. 관리자 경로·관리자 인증·IP 기반 접속 제한은 두지 않는다.
- 사용자 경로는 발송처가 전달한 **연동 요청 URL**(진입 경로 + encX·encY 파라미터)로 진입한다.
- **서버 대면 API에 인증을 두지 않는다.** 요청 제한도 두지 않는다. 이로 인한 리스크는 수용 대상이며 그 내용은 [`../PRD.md`](../PRD.md) §시스템 제약사항이 정본이다.
- **연동 규약 자가진단 API**는 상수로 고정한 비공개 경로(`<SELFCHECK_PATH>`)로만 노출한다([`external-apis.md`](external-apis.md) §연동 규약 자가진단 API).

## 미결

- 비밀 값(연결 문자열) 관리 수단, 로깅·모니터링 구성은 build 단계 상세.
- 라이브러리 빌드 PC 준비와 배포 전달 경로는 build 착수 시점 확정 사항이다.
