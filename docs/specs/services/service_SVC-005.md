# 연동 결과 안내 기능 정의

정본 목록은 [`spec-services.md`](spec-services.md). 용어는 [`../../../wiki/WIKI.md`](../../../wiki/WIKI.md).

## 개요

- **서비스 목적**: 연동이 어떻게 끝났는지를 **세 경로 중 하나로** 사용자에게 알린다. 결과가 이미 확정된 링크로 다시 들어와도 같은 경로를 다시 보여 주어, 사용자가 보는 결과와 발송처가 조회하는 결과가 어긋나지 않게 한다. **연동 완료 결과(경로 ①)에만 안내에 복귀 주소를 함께 실어** 여정이 결과 화면에서 끝나지 않고 사용자가 출발지로 돌아가게 한다 — 본 서비스는 **주소를 실을지 말지만** 정하고, 이동 자체와 이동까지의 대기는 화면이 수행한다.
- **관련 PRD 요구사항**:
	- [`../../prd/PRD.md`](../../prd/PRD.md) §수행 범위 6 — "결과를 **세 경로**로 구분해 사용자에게 표시한다 — 연동 완료 · 링크·복호화 오류 · 수신처 전달 실패. 결과가 이미 확정된 링크로 다시 진입하면 **그 결과 경로를 그대로 다시 안내**한다(경로를 추가하지 않는다)."
	- [`../../prd/PRD.md`](../../prd/PRD.md) §수행 범위 6 — "**연동 완료 결과만** 결과를 … 보여 준 뒤 **요청 처리 응답이 돌려준 복귀 주소로 자동 이동**한다 … **완료가 아닌 결과는 이동할 주소를 받지 못하므로**(허브가 복귀 주소를 싣지 않는다) 결과 화면에 머문다."
	- [`../../prd/devspec/database.md`](../../prd/devspec/database.md) §추적 키 중복 수신 3.

#### 분기 흐름

| 코드 | 발생 조건 | 분기 처리 | 결과 |
|------|----------|----------|------|
| BR-008 | 2단계 결과 구분 값 | `SUCCESS` → 경로 ① / `DECRYPT_FAILED` 또는 진입 단계 실패 → 경로 ② / `DELIVERY_FAILED` → 경로 ③ | 세 경로 중 하나로 안내 |
| BR-025 | 3단계에서 BR-008 이 고른 경로가 **연동 완료(경로 ①)**인지 | ① → 안내 정보에 복귀 주소를 싣는다 / ②·③ → 싣지 않는다. ① 이라도 값이 `https`·`http` 절대 URL 이 아니면 싣지 않는다(F-008) | 복귀 주소가 실린 안내(①) 또는 실리지 않은 안내(②·③) |
| BR-009 | 1단계에서 받은 것이 **이미 확정된 결과의 재진입**인 경우 | BR-008 로 같은 경로를 고르고, 보조 표시를 함께 구성한다. 계수·갱신은 하지 않는다 | 해당 경로 재표시 + 보조 표시 |
| BR-002 | 진입한 추적 키의 레코드 상태(`SVC-002` 에서 판정) | 결과 확정 상태이면 BR-009 로, 미확정이면 본인확인·동의 흐름으로 되돌린다 | 재안내 또는 정상 흐름 계속 |

- **BR-025 는 BR-008 의 후속 판정이다** — BR-008 이 고른 경로를 입력으로 받아 동봉 여부만 정한다. 결과 구분 값을 다시 읽지 않는다.
- **BR-025 는 BR-009 와 독립이다** — 재안내 여부는 BR-025 의 결과를 바꾸지 않는다. 재안내라도 경로가 ① 이면 복귀 주소를 싣고 ②·③ 이면 싣지 않는다(`BIZ-001-06`).
- **BR-025 에 코드를 부여한 이유** — ① 본 문서의 분기 흐름 표와 [프로세스 정의서](../processes/spec-process.md)의 분기 표가 **BR 코드로 식별되는 양식**이라 코드 없는 분기를 두면 후행 도메인이 인용할 좌표가 사라진다 ② 동봉 여부는 경로 선택(BR-008)과 **다른 판정**이며, 적용 경로가 확정된 뒤에도(`EXC-BIZ-15`) 그 조건을 바꾸려면 PRD 개정이 선행돼야 하므로 **변경 지점을 한 코드로 고정**해 둔다.

### 사용자 정의

- **사용자** — 안내를 받는 유일한 주체다. 안내는 사용자가 다음에 무엇을 해야 하는지 판단할 수 있는 수준까지만 담는다.
- **발송처** — 결과 안내 화면을 보지 않는다. 결과는 서버 대면 API 로 조회한다(푸시 통지 경로는 두지 않는다).

### 관련 서비스

- `SVC-001`·`SVC-002`·`SVC-003`·`SVC-004` — 결과·실패를 넘겨준다.
- `SVC-010` — 발송처가 같은 결과 구분을 조회로 확인한다. 두 표면이 같은 값 체계를 쓴다.
- `SVC-014` — 확정 결과의 출처가 되는 레코드를 보유한다.

### 예외 사항

- **네 번째 경로를 만들지 않는다.** 확정 결과 재안내도 새 경로가 아니라 기존 경로의 재표시 + 보조 표시다. **미동의로 끝난 연동에도 결과 경로를 부여하지 않는다** — 결과 단계로 오지 않기 때문이다(`BIZ-003-03`).
- **경로 ② 는 두 출처를 받는다** — 추적 레코드가 없는 진입 단계 실패와 `DECRYPT_FAILED`. 따라서 결과 구분 값이 없어도 이 경로를 그릴 수 있어야 한다.
- **확정 결과 재안내의 대상은 경로 ①·③ 이다.** 경로 ② 는 추적 레코드에 결과로 확정되는 경로가 없어 재안내 대상이 아니다(`BIZ-002-04` ③ · `EXC-BIZ-14`).
- **보관 기간이 지나 레코드가 삭제된 뒤의 재진입**은 확정 결과를 알 수 없으므로 새 연동으로 시작한다. 재안내가 아니다.
- 결과 안내의 문구·표시 형식·경로를 화면으로 어떻게 나눌지는 화면 도메인이 정한다. 본 사양은 **어떤 결과가 어느 경로로 가는지**, 그리고 **복귀 주소를 실을지 말지**만 정한다.
- **이동 실패는 네 번째 경로도 새 예외 코드도 만들지 않는다.** 창 차단·이동 불가는 이미 확정된 결과를 바꾸지 않는 **화면 후처리**이므로, **화면 잔류 + 수동 이동 수단**으로 흡수한다(`BIZ-001-06`). 그 수단의 형태는 화면 도메인이 정한다. 예외 코드를 만들면 오류 응답 엔벨로프가 필요해지고, 그 엔벨로프는 경로 ②·③ 으로 읽혀 확정된 결과를 뒤엎는다(`BIZ-001-04`).
- **복귀 주소의 출처가 미확정이다**([`../../prd/PRD.md`](../../prd/PRD.md) §미결·확인 필요 ⑦). 현재는 허브가 상수 `<COMPLETION_REDIRECT_URL>` 을 그대로 싣는다. 출처가 수신처 전달 응답 또는 발송처가 전달 데이터에 담아 보내는 값으로 확정되면 **본 서비스의 입력 출처(F-007 의 입력)가 바뀐다** — 동봉 여부 판정 규칙(F-007·F-008·BR-025)은 그대로 선다.
- **적용 경로는 연동 완료(경로 ①) 하나로 확정됐다**([`../../prd/PRD.md`](../../prd/PRD.md) §미결·확인 필요 ⑩ **확정 종결** · `EXC-BIZ-15`). 더는 담당자 확인 대기 항목이 아니다 — 완료가 아닌 결과는 허브가 복귀 주소를 싣지 않아 화면이 이동할 주소를 갖지 못한다. 대상 조건을 다시 넓히려면 PRD 개정이 선행돼야 한다.

### 구현 가이드

- 결과 구분은 문자열 상수 **세 개**로 한 곳에 정의하고 화면·API·집계가 그 정의를 가져다 쓴다. 화면에서 별칭·대소문자 변형을 만들지 않는다. 도달할 수 없는 값을 열거형에 남기지 않는다(`BIZ-001-01`).
- "결과 확정" 판정은 결과 구분 값의 존재 여부로 한다.
- 재안내 여부는 안내 구성 단계에서만 쓰는 표시 정보이며 저장 대상이 아니다.
- **결과 → 이동 여부 대응도 결과 → 경로 대응과 같은 한 곳에 둔다** — 경로 선택(BR-008)과 복귀 주소 동봉(BR-025)을 같은 안내 구성 지점에서 함께 결정하고, 화면·API 는 그 산출(필드 유무)만 읽는다. 화면에 경로 번호 기반의 두 번째 판정을 두지 않는다(`BIZ-001-06`).
- 복귀 주소 값은 상수 `<COMPLETION_REDIRECT_URL>` 로만 주입받는다. 값을 사양·코드 본문에 복제하지 않는다(`OPS-001-01`·`OPS-001-04`).
- 결과를 보여 주고 이동하기까지의 **대기 시간은 화면 사양이 정본**이다([`../screens/screen_SCR-004.md`](../screens/screen_SCR-004.md)) — 본 사양은 시간 값을 갖지 않는다.
