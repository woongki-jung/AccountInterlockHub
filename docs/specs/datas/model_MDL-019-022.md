# 배포·운영 데이터 모델 정의 (MDL-019 ~ MDL-022)

정본 목록은 [`spec-models.md`](spec-models.md). 용어는 [`../../../wiki/WIKI.md`](../../../wiki/WIKI.md).

## 개요

- **모델 목적**: 런타임 요청 흐름 밖에서 쓰이는 값 넷이다 — 발송처에 전달하는 **규약 테스트 벡터**와 **배포 패키지 구성**, 보관 배치의 **실행 결과 요약**, 그리고 기동 시 주입되는 **연동 구성 상수 집합**. 넷 다 저장되지 않는다.
- **관련 서비스**: `SVC-008`(배포 패키지 제공) · `SVC-009`(규약 테스트 벡터 제공) · `SVC-017`(보관정책 배치) · `SVC-018`(연동 구성 상수 검증)

| boundaryNote | string | Y | - | 빈 값 불가 | - | 이 항목이 덮는 규약 경계(키 원문 길이 미만·일치·초과, Base64URL 치환 문자 등) |
| input | object | Y | - | `senderKey`·`birthDate`·`payload` 셋 | - | 알려진 입력 |
| input.senderKey | string | Y | - | **예시 값만** 쓴다 | - | 발송처키 자리 |

- **실 사용자 생년월일·실 발송처키·실 회원 정보를 넣지 않는다**(`DATA-001-02`·`DATA-001-04`) — 벡터는 배포 패키지에 담겨 저장소와 발송처 양쪽에 남는 문서다.
- 같은 입력이 항상 같은 출력을 내는 규약이라 값 대조가 성립한다. 규약이 바뀌면 벡터를 다시 만들고 대조 통과를 배포 전제로 삼는다(`SEC-001-12`).

### 엔터티 매핑

**매핑 엔터티 없음** — 배포 산출물이며 허브 데이터베이스와 무관하다.

### 사용처

| SVC 코드 | 기능 | 용도 (요청/응답/도메인) | 사용 PROC | 비고 |
|----------|------|------------------------|----------|------|
| SVC-009 | 규약 테스트 벡터 제공 | 도메인 | PROC-404 | 생성·대조의 대상 |
| SVC-008 | 배포 패키지 제공 | 도메인 | PROC-403 | 패키지 동봉 구성 요소 |

### 구현 가이드

- 사람이 읽고 기계가 파싱할 수 있는 형태로 둔다. 발송처의 자체 확인과 검증 절차가 같은 파일을 쓴다.
- 각 항목에 어떤 경계를 덮는지(`boundaryNote`) 표시해 두면 규약 개정 시 어느 항목을 다시 만들어야 하는지 판단하기 쉽다.

## MDL-021 보관 배치 실행 결과 요약

### 기본 정보

| 항목 | 내용 |
|------|------|
| 모델명 | 보관 배치 실행 결과 요약 |
| 분류 | 서비스(SVC) |
| 사용 서비스 | SVC-017 |
| 매핑 엔터티 | **없음(비저장)** |
| 사용 PROC | PROC-304 |
| 용도 | 응답 모델(표준 출력) |
| 관련 IA 항목 | `BAT-02` |

### 속성 정의

| 속성명 | 데이터 타입 | 필수 | 기본값 | 유효성 규칙 | 마스킹 규칙 | 설명 |
|--------|-----------|------|--------|-------------|-------------|------|
| baseAt | datetime | Y | - | 실행 시점에 산정한 값 | - | 삭제 대상 산정의 기준 일시 |
| trackingDeletedCount | number(정수) | Y | 0 | 0 이상 | - | 삭제한 연동 추적 레코드 건수 |
| consentProofDeletedCount | number(정수) | Y | 0 | 0 이상 | - | 삭제한 동의 증적 건수 |
| failureReason | string \| null | N | null | 성공이면 null | - | 실패 사유. 종료 코드로는 성공·실패만 구분하므로 세부는 여기 담는다 |

- **지표 집계 삭제 건수 항목을 두지 않는다** — 삭제 대상이 아니므로 셀 것이 없다(`DATA-002-03`).
- **고정된 키·값 구조**로 표준 출력에 내보내 검증 절차가 그대로 파싱할 수 있게 한다(`OPS-003-04`).
- 별도 실행 이력 저장소를 두지 않는다 — 이 요약과 종료 코드가 유일한 관측 수단이다.

### 엔터티 매핑

**매핑 엔터티 없음** — 실행 결과를 저장하지 않는다. 대상별 삭제 건수는 ENT-001·ENT-002 의 DELETE 결과에서 집계되며 어디에도 기록되지 않는다.

### 사용처

| SVC 코드 | 기능 | 용도 (요청/응답/도메인) | 사용 PROC | 비고 |
|----------|------|------------------------|----------|------|
| SVC-017 | 보관정책 배치 | 응답 | PROC-304 | 스케줄 실행·수동 실행이 같은 요약을 낸다 |

### 구현 가이드

- 삭제는 **대상별로 분리해 세고** 요약에 각 건수를 담는다. 이것이 검증의 관측 지점이다.
- 성공은 종료 코드 0, 실패는 0 이외로만 구분한다. 두 진입 경로(스케줄·수동)가 같은 요약과 같은 종료 코드 규칙을 쓴다.
- 멱등하다 — 같은 날 여러 번 실행하면 두 번째부터 건수가 0 이 된다(`DATA-002-04`).

## MDL-022 연동 구성 상수 집합

### 기본 정보

| 항목 | 내용 |
|------|------|
| 모델명 | 연동 구성 상수 집합 |
| 분류 | 공통(COM) |
| 사용 서비스 | SVC-005 · SVC-017 · SVC-018 (검증 통과 후 전 서비스가 소비) |
| 매핑 엔터티 | **없음(비저장 · 상수 유래)** |
| 사용 PROC | PROC-105 · PROC-304 · PROC-901 |
| 용도 | 도메인 모델 |
| 관련 IA 항목 | 공통 |

### 속성 정의

값은 배포 시점에 주입되며 **본 사양에 복제하지 않는다**(`OPS-001-04`). 단일 출처는 [`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §연동 구성 상수다.

| 속성명 | 데이터 타입 | 필수 | 기본값 | 유효성 규칙 | 마스킹 규칙 | 설명 |
|--------|-----------|------|--------|-------------|-------------|------|
| interlockEntryPath | string | Y | - | 경로 형태 | - | `<INTERLOCK_ENTRY_PATH>` — 사용자 진입 경로 |
| selfcheckPath | string | Y | - | 경로 형태 | **소스·정적 자산·프런트엔드 산출물·응답 어디에도 담지 않는다**(`SEC-003-01`·`SEC-003-02`) | `<SELFCHECK_PATH>` — 자가진단 비공개 경로. 운영 값은 배포 시 주입되는 비밀 값이다 |
| receiverDeliveryUrl | string | Y | - | URL 형태 | - | `<RECEIVER_DELIVERY_URL>` — 수신처 전달 주소 |
| consentItems | [`MDL-008`](model_MDL-007-010.md)`.items` | Y | - | 배열 구조와 필수 속성을 갖춘다 | - | `<CONSENT_ITEMS>` 파싱 대상 |
| consentNotice | string | N | 빈 문자열 | 허용 형태는 상수표가 정본 | - | `<CONSENT_NOTICE>` |
| retentionMonths | number(정수) | Y | - | 양의 정수 | - | `<RETENTION_MONTHS>` — 결과 확인 완료 기산 |
| retentionMaxMonths | number(정수) | Y | - | 양의 정수 | - | `<RETENTION_MAX_MONTHS>` — 생성 기산 절대 상한 |
| consentProofRetentionMonths | number(정수) | Y | - | 양의 정수 | - | `<CONSENT_PROOF_RETENTION_MONTHS>` — 동의 증적 보존 |
| completionRedirectUrl | string | Y | - | URL 형태 — `https://`·`http://` 로 시작하는 절대 URL(`BIZ-001-06`) | - | `<COMPLETION_REDIRECT_URL>` — **연동 완료 결과(경로 ①)에만** 실어 주는 사용자 복귀 주소 |

- **허브 기준 URL(`<HUB_BASE_URL_PROD>`·`<HUB_BASE_URL_DEV>`)은 이 모델에 담지 않는다** — 허브에 주입되는 값이 아니라 발송처가 라이브러리 호출 인자로 넘기는 값이라 소유 주체가 다르다(EXC-OPS-04·`SVC-018` F-007).
- 하나라도 충족하지 않으면 **기동을 중단**하고 미충족 항목을 모두 모아 한 번에 알린다(`OPS-001-02` → 사유 코드 `EX-OPS-001`).
- **잠정값 여부는 판별하지 않는다** — 잠정 상태의 운영 배포 방지는 배포 절차의 확인 항목이다(`OPS-001-03`).
- **`completionRedirectUrl` 은 존재와 형식만 확인한다**(`SVC-018` F-002) — 주소에 실제로 접속해 도달 가능 여부를 보지 않는다. 잠정값이 실 호스트로 연결되는 주소라 교체 누락은 애플리케이션이 아니라 배포 절차 확인이 막는다(`OPS-001-03`·EXC-OPS-01). 응답에 싣는 조건은 [`MDL-009`](model_MDL-007-010.md) 와 `BIZ-001-06` 이 갖는다.

### 엔터티 매핑

**매핑 엔터티 없음** — 연동 구성은 데이터베이스에 두지 않는다(`DATA-001-05`). 구성 테이블·구성 API 를 만들지 않는다. 값 변경은 재배포로만 반영된다(`OPS-001-01`).

### 사용처

| SVC 코드 | 기능 | 용도 (요청/응답/도메인) | 사용 PROC | 비고 |
|----------|------|------------------------|----------|------|
| SVC-018 | 연동 구성 상수 검증 | 도메인 | PROC-901 | 로드·형식 검증·버전 식별자 산출의 입력 |
| SVC-017 | 보관정책 배치 | 도메인 | PROC-304 | 보관 기간 상수로 기준 일시를 계산한다 |
| SVC-005 | 연동 결과 안내 | 도메인 | PROC-105 | `completionRedirectUrl` 을 읽어 **경로 ① 안내에만** 복귀 주소를 싣는다(`BIZ-001-06`). 호출측이 실어 오지 않고 결과 안내 구성이 상수에서 직접 읽는다 |

### 구현 가이드

- 애플리케이션 설정 값으로만 주입받는다. 기동 시 한 번 읽어 불변 값으로 보유한다.
- 기동 검증은 모든 미충족 항목을 모아 한 번에 보고한 뒤 중단한다. 하나씩 실패시키면 배포자가 여러 번 재시도해야 한다.
- 보관 기간 값은 실행 시점에 기준 일시를 계산하는 데 쓰고 코드에 박지 않는다. 값이 코드에 박히면 확정 시 재작성이 필요해진다.
