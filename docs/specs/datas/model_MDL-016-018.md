# 연동 라이브러리 데이터 모델 정의 (MDL-016 ~ MDL-018)

정본 목록은 [`spec-models.md`](spec-models.md). 용어는 [`../../../wiki/WIKI.md`](../../../wiki/WIKI.md).

## 개요

- **모델 목적**: 발송처가 연동 라이브러리를 호출할 때 넘기고 받는 값 셋이다 — **암호화 입력**, **요청 URL 생성 입력**, 그리고 결과인 **연동 요청 URL**. 라이브러리는 허브 애플리케이션과 별도 배포 단위이며 이 모델들은 허브 데이터베이스와 무관하다.
- **관련 서비스**: `SVC-006`(전달 데이터 암호화) · `SVC-007`(연동 요청 URL 생성) · `SVC-001`(URL 로 진입)
- 소스 경로·산출물명·대상 런타임은 [`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §연동 라이브러리 식별자가 단일 출처다 — 본 사양에 값을 복제하지 않는다(`OPS-001-04`).

---

## MDL-016 라이브러리 암호화 입력

### 기본 정보

| 항목 | 내용 |
|------|------|
| 모델명 | 라이브러리 암호화 입력 |
| 분류 | 외부 연동(EXT) |
| 사용 서비스 | SVC-006 |
| 매핑 엔터티 | **없음(비저장)** |
| 사용 PROC | PROC-401 |
| 용도 | 외부 DTO |
| 관련 IA 항목 | `LIB-01` |

### 속성 정의

| 속성명 | 데이터 타입 | 필수 | 기본값 | 유효성 규칙 | 마스킹 규칙 | 설명 |
|--------|-----------|------|--------|-------------|-------------|------|
| payload | [`MDL-005`](model_MDL-004-006.md) | Y | - | UTF-8 직렬화 결과가 평문 크기 상한 이하(`SEC-001-09` → 위반 시 사유 코드 `EX-SEC-004`) | **예외 메시지·로그에 담지 않는다**(`DATA-001-04`) | 전달 데이터 X |
| senderKey | string | Y | - | 빈 값 불가. 형식 제약을 두지 않는다(발송처 소관) | **어떤 저장소·로그·예외 메시지에도 담지 않는다**(`DATA-001-02`) | 발송처키. 라이브러리에 내장하지 않고 호출 시 받는다 |
| birthDate | string(6) | Y | - | [`MDL-006`](model_MDL-004-006.md) 와 같은 기준(`^\d{6}$`) | 위와 같다 | 사용자 생년월일 |

- **발송처키는 상수화 대상이 아니다** — 비밀 값이라 상수표에 두지 않으며 허브도 보관하지 않는다([`../../../CLAUDE.env.md`](../../../CLAUDE.env.md) §발송처 호출 입력 값 주석).
- 산출 결과는 [`MDL-004`](model_MDL-004-006.md) 암호값 쌍이다.

### 엔터티 매핑

**매핑 엔터티 없음** — 라이브러리는 허브 데이터베이스에 접근하지 않는다. 저장 지점이 존재하지 않으며, 세 값 모두 호출이 끝나면 폐기된다.

### 사용처

| SVC 코드 | 기능 | 용도 (요청/응답/도메인) | 사용 PROC | 비고 |
|----------|------|------------------------|----------|------|
| SVC-006 | 전달 데이터 암호화 | 요청 | PROC-401 | 규약 위반은 라이브러리 전용 예외로 알린다 |

### 구현 가이드

- **정규화 순서를 지킨다** — 발송처키와 생년월일을 이어 붙인 **뒤** 키 정규화를 적용한다. 각각 정규화한 뒤 이어 붙이면 다른 키가 나온다(`SEC-001-05`).
- 규약 위반과 런타임 오류를 구별 가능한 예외로 알리고 사유를 코드로 식별할 수 있게 한다(BR-020). 사유 코드는 자가진단이 쓰는 값과 같다.
- 공개 진입점은 호출 간 상태를 공유하지 않는다(동시 호출 안전).

## MDL-017 요청 URL 생성 입력

### 기본 정보

| 항목 | 내용 |
|------|------|
| 모델명 | 요청 URL 생성 입력 |
| 분류 | 외부 연동(EXT) |
| 사용 서비스 | SVC-007 |
| 매핑 엔터티 | **없음(비저장)** |
| 사용 PROC | PROC-402 |
| 용도 | 외부 DTO |
| 관련 IA 항목 | `LIB-02` |

### 속성 정의

| 속성명 | 데이터 타입 | 필수 | 기본값 | 유효성 규칙 | 마스킹 규칙 | 설명 |
|--------|-----------|------|--------|-------------|-------------|------|
| hubBaseUrl | string | Y | - | 절대 URL 형태. 끝 구분자 유무에 관계없이 같은 결과가 나와야 한다 | - | 허브 기준 URL. 환경별로 다르므로 **호출 인자로 받는다**(라이브러리에 내장하지 않는다) |
| encPair | [`MDL-004`](model_MDL-004-006.md) | Y | - | Base64URL 형태 그대로 | **로그·예외 메시지에 담지 않는다** | 결합할 암호값 쌍 |

- `hubBaseUrl` 의 값은 `<HUB_BASE_URL_PROD>`·`<HUB_BASE_URL_DEV>` 이며 **잠정값**이다. 상수 주입으로만 참조하고 본 사양에 값을 복제하지 않는다. 발송처는 배포 패키지 사용 안내의 기재란에서 자기 환경 값을 확인한다([`MDL-020`](model_MDL-019-022.md)).
- 진입 경로는 상수 `<INTERLOCK_ENTRY_PATH>` 로 고정되며 경로에 발송처 식별 구간을 두지 않는다.

### 엔터티 매핑

**매핑 엔터티 없음** — 라이브러리는 허브 데이터베이스에 접근하지 않는다.

### 사용처

| SVC 코드 | 기능 | 용도 (요청/응답/도메인) | 사용 PROC | 비고 |
|----------|------|------------------------|----------|------|
| SVC-007 | 연동 요청 URL 생성 | 요청 | PROC-402 | 산출 결과는 [`MDL-018`](#mdl-018-연동-요청-url) |

### 구현 가이드

- 기준 URL 의 끝 구분자 유무에 관계없이 같은 결과가 나오도록 결합한다. 발송처마다 다른 형태로 값을 넘겨도 결과가 흔들리지 않아야 한다.
- 파라미터 이름은 허브의 진입 파싱과 **정확히 같은 이름**을 쓴다. 이름의 확정은 기능·API 도메인 소관이며 라이브러리와 허브가 같은 값을 공유한다.
- 기준 URL·진입 경로 값을 라이브러리에 박지 않는다(`OPS-001-04`).

## MDL-018 연동 요청 URL

### 기본 정보

| 항목 | 내용 |
|------|------|
| 모델명 | 연동 요청 URL |
| 분류 | 외부 연동(EXT) |
| 사용 서비스 | SVC-001 · SVC-007 |
| 매핑 엔터티 | **없음(비저장)** |
| 사용 PROC | PROC-101 · PROC-402 |
| 용도 | 외부 DTO |
| 관련 IA 항목 | `LIB-02` · `USR-01` |

### 속성 정의

| 속성명 | 데이터 타입 | 필수 | 기본값 | 유효성 규칙 | 마스킹 규칙 | 설명 |
|--------|-----------|------|--------|-------------|-------------|------|
| url | string | Y | - | 전체 길이가 규약 상한 이하(`SEC-001-10` → 초과 시 `EX-SEC-004`). 판정은 조립을 마친 최종 문자열 기준 | **암호값을 포함하므로 로그·응답 본문에 담지 않는다**(`DATA-001-04`) | 발송처가 사용자에게 전달하는 연동 요청 URL |

- URL 에 **만료·1회성 표시를 두지 않는다** — 링크 만료(TTL)·1회성 사용은 이번 범위가 아니다(`OPS-002-05`).
- 자가진단 경로 값을 이 URL 에 담지 않는다(`SEC-003-02`).

### 엔터티 매핑

**매핑 엔터티 없음** — URL 은 저장되지 않는다. 진입 시점에 담긴 암호값만 [`MDL-004`](model_MDL-004-006.md) 로 읽히며, 그 값도 저장되지 않는다.

### 사용처

| SVC 코드 | 기능 | 용도 (요청/응답/도메인) | 사용 PROC | 비고 |
|----------|------|------------------------|----------|------|
| SVC-007 | 연동 요청 URL 생성 | 응답 | PROC-402 | 길이 판정을 통과한 값만 반환한다 |
| SVC-001 | 연동 링크 진입 | 요청 | PROC-101 | 길이 상한 재판정 후 암호값을 읽는다 |

### 구현 가이드

- 라이브러리와 허브가 **같은 길이 상한**을 쓴다. 생성 시 통과한 URL 이 진입에서 거부되면 발송처가 원인을 좁힐 수 없다.
- 전달 데이터가 클수록 암호값이 길어진다. 발송처는 평문 크기 상한과 URL 길이 상한을 함께 고려해 전달 데이터를 구성한다.
- 링크를 확보한 누구든 진입할 수 있다 — 진입 자체를 막는 장치가 없다(`OPS-002-05` 수용 리스크). 이 모델에 접근 제어 속성을 두지 않은 이유다.
