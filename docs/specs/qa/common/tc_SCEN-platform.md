# 횡단 시나리오 테스트 케이스 정의 — 기동·데이터 원칙·설계된 부재

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).
같은 횡단 식별자의 사용자 여정·규약 왕복 시나리오는 [`tc_SCEN-journey.md`](tc_SCEN-journey.md).

## 개요

- **검증 목적**: 특정 IA 노드에 매이지 않는 **플랫폼 계층 성질**을 검증한다 — 기동 시 상수 검증(`SVC-018`·`PROC-901`), 무저장·개인정보 최소 원칙, 그리고 이 제품이 **두지 않기로 결정한 것들**(관리자 표면·계정·요청 제한·감사 저장소)이 실제로 없는지 확인한다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §시스템 제약사항 — "**공개 표면**: 사용자 진입 경로와 서버 대면 API만 외부에 노출된다. 관리자 경로·관리자 인증·IP 기반 접속 제한은 두지 않는다." · "**데이터 원칙**: 저장 대상은 **연동 추적 레코드 · 동의 증적 · 연동 지표 집계 셋**이며 …" · "**접근 통제 없음 (수용 리스크)**".
- **관련 IA 항목**: `공통` (횡단). `SVC-018` 은 IA 좌표가 `공통` 이므로 본 파일이 담당한다.
- **검증 방법(qa 케이스)**: **API·서버** 를 주 절차로 하고 웹·SPA UI · CLI·배치 절차를 항목별로 병용한다.
- **공통 전제**: `ENV-API` · `ENV-WEB` · `ENV-CLI` · `ENV-DB` 기동 가능 상태 · 상수 구성 세트(`SEED-CONST-*`)
- **공통 판정 기준**: **Pass** = 전 단계의 확인 항목 일치 / **Fail** = 하나 이상 불일치(불일치 단계 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-901.md`](../../processes/process_PROC-901.md) 의 라벨(`C1`·`C2` · `B1`~`B7`)을 인용한다.
