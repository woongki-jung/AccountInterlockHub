# 연동 규약 자가진단 API 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 발송처가 통합 시점에 자기 암호값의 규약 적합성만 확인하는 접점이 **허브와 같은 판정 절차**를 쓰면서도 **아무것도 기록·전달하지 않는지** 확인한다. 이 접점의 유일한 완화 장치가 경로 비공개이므로, **비공개 경로에서만 응답하고 다른 경로로는 존재조차 드러내지 않는 것**이 핵심 검증 대상이다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 8 — "**연동 규약 자가진단 API**: 발송처가 만든 암호값의 규약 적합성만 판정해 응답한다. 수신처 전달·기록을 하지 않고 복호화 원문도 반환하지 않는다. 노출 경로는 상수로 고정한 **비공개 경로**다."
- **관련 IA 항목**: `API-04` (본 파일의 전 TC 공통)
- **검증 방법(qa 케이스)**: **API·서버**
- **공통 전제**: `ENV-API` 기동 · `ENV-DB` 시드 투입 완료 · `SEED-CONST-OK` 상수 주입(`<SELFCHECK_PATH>` 주입 값을 검증 절차만 보유)
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-204.md`](../../processes/process_PROC-204.md) 의 라벨(`C1`·`C2` · `B1`~`B6`)을 인용한다.
- **엔드포인트**: `POST <SELFCHECK_PATH>` — 요청 `MDL-014` · 응답 `MDL-015`. **본 문서는 경로 값을 적지 않는다**(`SEC-003-02`).

### API-04_010 메서드 불일치도 405 가 아닌 일반 404

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| POL · 권한/인증 | `SEC-003-02` · 인터페이스 §경로·메서드 규약 | PROC-204 | BR-014(메서드 불일치) | 높음 | 자동 |

- **전제**: `SEED-CONST-OK` 로 기동
- **단계**: ① 자가진단 경로에 GET 요청 `B1` → **404**(405 가 아니다) ② PUT·DELETE·HEAD·OPTIONS 도 전건 404 ③ 다른 서버 대면 API 는 메서드 불일치 시 **405** 임을 대조(자가진단만 다르다) ④ 405 를 돌려주면 경로의 존재가 드러남을 근거로 기록. **다만 이 조치로 존재가 완전히 감춰지는 것은 아니다** — `POST` + 해석 불가 본문에서는 실경로가 400 `EX-SEC-003` 으로 갈려 존재가 드러나며(`API-04_016`), 그것은 `OPS-002-06` 상 **수용된 성질**이다. 본 단계가 지키는 것은 "노출 범위를 줄인다"까지이고 "존재를 감춘다"가 아니다
- **판정**: 공통 판정 기준. **AUTH 치환** — 경로 비공개가 이 제품의 (수신처 전달의 서버 간 호출과 함께) 둘뿐인 완화 장치임을 확인한다(EXC-OPS-05). **그 효력 범위는 `OPS-002-06` 이 정한 만큼으로 한정된다** — **경로 값 자체의 추측 난이도**에만 기대는 장치이고 반복 시도를 막는 완화가 아니다. 따라서 본 TC 의 통과를 "경로가 드러나지 않는다"는 결론으로 확대 해석하지 않는다.

### API-04_011 인증 없이 호출 가능 — 경로 비공개는 인증이 아니다

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| POL · 권한/인증 | `AUTH-001-03` · EXC-AUTH-01 · EXC-SEC-09 · `OPS-002-03` · **`OPS-002-06`** | PROC-204 | BR-014(일치) | 높음 | 자동 |

- **전제**: `SEED-VEC-01`(파일)
- **단계**: ① 경로를 아는 요청을 인증 헤더 없이 POST `B1` → **그대로 처리**(경로를 아는 요청은 처리된다) ② 임의 자격을 실어도 검증 없이 같은 결과 ③ 같은 값으로 **50회 연속 호출** → 차단·지연·잠금이 발생하지 않는다(요청 제한 부재 — 수용 리스크) ④ 이 상태가 결함이 아니라 수용된 성질임을 기록한다. **경로 비공개가 이 접점의 유일한 장치이지만, 그 장치는 여기서 아무것도 막지 못한다** — `OPS-002-06` 상 경로 비공개는 **경로 값의 추측 난이도**에만 기대는 장치이므로 **경로를 이미 아는 요청 앞에서는 효력이 0** 이고, 경로가 드러난 뒤의 반복 시도는 `OPS-002-03` 의 수용 범위에 그대로 든다. "완화 장치가 있으니 반복 시도는 어느 정도 막힌다"는 결론을 세우지 않는다 ⑤ 요청 제한을 도입한 흔적(429·지연·잠금)이 없음을 확인 — 도입은 반려 대상이다(`OPS-002-05`)
- **판정**: 공통 판정 기준. **AUTH 치환** — 인증 부재 + 요청 제한 부재의 **수용 리스크 확인**이며 실패로 판정하지 않는다(EXC-OPS-07).

### API-04_016 `POST` + 해석 불가 본문 — 실경로와 디코이가 갈린다(수용된 성질)

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| POL · Negative | **`OPS-002-06`**(경로 비공개의 효력 범위) · EXC-OPS-10 · `SEC-003-04` · `SEC-003-02` · `OPS-002-03`·`OPS-002-05` · EXC-OPS-05·EXC-OPS-07 | PROC-204 | BR-014 · `EX-SEC-003` | 보통 | 자동 |

- **전제**: `SEED-CONST-OK` 로 기동 · 자가진단 경로 값은 검증 절차만 보유 · 디코이 경로 집합(존재하지 않는 경로 · `API-04_009` ②③ 과 같은 세트)
- **단계**: ① **실경로**에 `POST` + **해석 불가 본문**(깨진 JSON·빈 본문·JSON 아닌 바이트)을 보낸다 `B2` → **400 `EX-SEC-003`**(`SEC-003-04` 가 명시로 요구한다 — `API-04_007` ③ 과 같은 귀결) ② **디코이 경로**에 **완전히 같은 요청**을 보낸다 `B1` → **본문 없는 일반 404** ③ 두 응답을 대조 → **상태 코드·본문·헤더가 서로 다르다.** 즉 **요청 1건으로 경로의 존재가 확인된다** ④ 이 갈림이 **결함이 아니라 `OPS-002-06` 상 수용된 성질**임을 판정 근거에 기록한다 — 경로 비공개는 **경로 값의 추측 난이도**에만 기대는 장치이고, **응답이 서로 구분되지 않는 성질에는 기대지 않는다.** 요청 제한도 없어(`OPS-002-05`) 후보 경로 열거를 막지도 못한다 ⑤ **역방향 확인 — 400 이 일반 404 로 바뀌어 있으면 Fail 이다.** 진단 응답을 404 로 뭉개는 선택지는 `EXC-OPS-10` 으로 **명시 기각**됐다(자가진단이 주는 능력은 복호화 성공 여부 판정 하나이고, 그 능력은 경로를 몰라도 공개된 본인확인 재입력에서 횟수 제한 없이 이미 얻어지므로 진단성을 버려도 대가로 보호되는 것이 없다) ⑥ 경로가 드러난 뒤의 반복 시도가 `OPS-002-03` 수용 범위에 그대로 든다는 것을 `API-04_011` ③④ 와 연결해 기록
- **판정**: 공통 판정 기준. **실패로 판정하지 않는다**(EXC-OPS-07) — 본 TC 는 리스크가 **실제로 존재함을 고정**하는 것이 목적이다. 다만 ①(400 `EX-SEC-003` 미발생)과 ⑤(일반 404 로 대체)는 **사양 위반이므로 Fail** 이다. 즉 "구분된다"는 사실은 Pass 이고, "구분되지 않게 바꿔 놓은 것"이 Fail 이다.
