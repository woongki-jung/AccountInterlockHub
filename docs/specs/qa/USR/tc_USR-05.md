# 연동 결과 안내 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 연동의 끝을 **정확히 세 경로 중 하나**로만 안내하는지, 네 번째 경로가 어떤 입력으로도 만들어지지 않는지 확인한다. 확정 결과 재안내가 새 경로가 아니라 **같은 경로 + 보조 표시**로 처리되는 것, 그리고 **연동 완료(경로 ①)에서만 복귀 주소로 이동**하고 나머지는 잔류하는 것도 이 노드의 핵심 검증 대상이다.
- **관련 PRD 요구사항**:
	- [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 6 — "결과를 **세 경로**로 구분해 사용자에게 표시한다 — 연동 완료 · 링크·복호화 오류 · 수신처 전달 실패. 결과가 이미 확정된 링크로 다시 진입하면 **그 결과 경로를 그대로 다시 안내**한다(경로를 추가하지 않는다)."
	- [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 6 — "**연동 완료 결과만** 결과를 **3초** 보여 준 뒤 **요청 처리 응답이 돌려준 복귀 주소로 자동 이동**한다 … **완료가 아닌 결과는 이동할 주소를 받지 못하므로** 결과 화면에 머문다."
- **관련 IA 항목**: `USR-05` (본 파일의 전 TC 공통. 결과는 `USR-01`·`USR-02`·`USR-03`·`USR-04` 어디에서든 흘러든다)
- **검증 방법(qa 케이스)**: **웹·SPA UI**
- **공통 전제**: `ENV-WEB` 기동 · `ENV-DB` 시드 투입 완료 · `SEED-CONST-OK` 상수 주입(복귀 주소 상수 `<COMPLETION_REDIRECT_URL>` 포함 — **실값을 본 문서군에 적지 않는다**)
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-105.md`](../../processes/process_PROC-105.md) 의 라벨(`B1`~`B3` · `F1`~`F3`)을 인용한다.
- **결번 TC**: `USR-05_002` (사용자 거부 패널 — 거부가 결과 경로에서 폐지돼(`BIZ-003-03`) 검증 대상 패널 자체가 없어졌다. 번호를 다른 뜻으로 재사용하지 않는다). `USR-05_003`·`_004` 는 **검증 대상 패널을 그대로 유지**한 채 경로 번호만 ③→② · ④→③ 으로 당겨 표기한다.

### USR-05_001 경로 ① 연동 완료 패널

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| UI · Positive | SVC-005 · MDL-009 · SCR-004 §결과 3경로 · `BIZ-001-02` ① | PROC-105 | BR-008(`SUCCESS`) | 높음 | 자동 |

- **전제**: `SEED-VEC-01`(파일) · `MOCK-RCV` 200 모드로 연동을 완료
- **단계**: ① 승인 응답 수신 `B1`·`B2` → `resultPath = 1` ② 화면 렌더 `F1`·`F2` → 초록·원 안 체크 아이콘(40px) · 제목 "연동이 완료되었습니다" · 설명 "요청하신 연동이 정상적으로 처리되었습니다." · 다음 안내 **"이 화면에서 더 하실 일은 없습니다."**(창을 닫으라고 말하지 않는다 — 곧 이동하는 경로이기 때문이다) ③ 재시도 버튼·문의처가 없고 **조작 요소는 복귀 안내 영역의 수동 이동 링크뿐**임을 확인 ④ 배지 `재안내` 가 없음을 확인(`isReAnnouncement = false`)
- **판정**: 공통 판정 기준

### USR-05_002 (결번)

사용자 거부가 결과 경로에서 폐지돼(`BIZ-003-03` · `BIZ-001-02`) 이 TC 가 검증하던 패널이 사라졌다. **뒤 번호를 당기지 않는다** — 당기면 `_003`·`_004` 가 다른 패널을 가리키게 되어 후행 문서의 인용이 어긋난다.

### USR-05_006 확정 결과 재안내 — 배지·덧붙인 문장·무갱신

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |

- **판정**: 공통 판정 기준. 현재 값이 **개발용 더미**이며 주소의 출처가 미확정(PRD §미결·확인 필요 ⑦)이라는 사실은 결함이 아니다 — 출처가 확정돼도 **값을 얻는 자리만** 바뀌고 동봉 규칙·필드 형상은 그대로다.
