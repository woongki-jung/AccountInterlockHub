# 연동 결과 안내 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 연동의 끝을 **정확히 네 경로 중 하나**로만 안내하는지, 다섯 번째 경로가 어떤 입력으로도 만들어지지 않는지 확인한다. 확정 결과 재안내가 새 경로가 아니라 **같은 경로 + 보조 표시**로 처리되는 것도 이 노드의 핵심 검증 대상이다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 6 — "결과를 네 경로로 구분해 사용자에게 표시한다 — 연동 완료 · 사용자 거부 · 링크·복호화 오류 · 수신처 전달 실패. 결과가 이미 확정된 링크로 다시 진입하면 **그 결과 경로를 그대로 다시 안내**한다(경로를 추가하지 않는다)."
- **관련 IA 항목**: `USR-05` (본 파일의 전 TC 공통. 결과는 `USR-01`·`USR-02`·`USR-03`·`USR-04` 어디에서든 흘러든다)
- **검증 방법(qa 케이스)**: **웹·SPA UI**
- **공통 전제**: `ENV-WEB` 기동 · `ENV-DB` 시드 투입 완료 · `SEED-CONST-OK` 상수 주입
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-105.md`](../../processes/process_PROC-105.md) 의 라벨(`B1`~`B3` · `F1`~`F3`)을 인용한다.

### USR-05_001 경로 ① 연동 완료 패널

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| UI · Positive | SVC-005 · MDL-009 · SCR-004 §결과 4경로 · `BIZ-001-02` ① | PROC-105 | BR-008(`SUCCESS`) | 높음 | 자동 |

- **전제**: `SEED-VEC-01`(파일) · `MOCK-RCV` 200 모드로 연동을 완료
- **단계**: ① 승인 응답 수신 `B1`·`B2` → `resultPath = 1` ② 화면 렌더 `F1`·`F2` → 초록·원 안 체크 아이콘(40px) · 제목 "연동이 완료되었습니다" · 설명 "요청하신 연동이 정상적으로 처리되었습니다." · 다음 안내 "이 창은 닫으셔도 됩니다." ③ 버튼·재시도·문의처가 없음을 확인 ④ 배지 `재안내` 가 없음을 확인(`isReAnnouncement = false`)
- **판정**: 공통 판정 기준

|---|---|---|---|---|---|

### USR-05_006 확정 결과 재안내 — 배지·덧붙인 문장·무갱신

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| E2E · 상태전이 | `BIZ-002-04` · SCR-004 §확정 결과 재안내 · MDL-009 | PROC-105 · PROC-102 | BR-009 · BR-002(③) | 높음 | 자동 |

- **전제**: `SEED-TRK-FIXED-SUCCESS`·`SEED-TRK-FIXED-DENIED`·`SEED-TRK-FIXED-DELIVERY`(SQL) + 대응 암호값 쌍(파일)
- **단계**: ① 확정 레코드 3종 각각에 대해 같은 링크로 재진입·본인확인 통과 `B3` → `isReAnnouncement = true` ② 화면 `F2` → **최초 안내와 같은** 색·아이콘·제목·다음 안내 + 배지 "이미 처리된 요청입니다"(제목 바로 아래·설명 문단 위) + 설명 끝 문장 "이 연동은 앞서 처리가 끝났고, 지금 보시는 결과가 그때 확정된 결과입니다." ③ 배지가 제목보다 앞서지 않는지 확인
- **데이터 검증**: 세 레코드의 `result_code`·`result_at`·`result_confirmed_at`·`callback_received_at` 전부 불변 · 지표 카운터 5종 전부 무변화
