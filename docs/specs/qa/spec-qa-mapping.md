# 스펙 코드 → 검증 TC 매핑 요약

정본 목록은 [`spec-qa.md`](spec-qa.md). 용어는 [`../../../wiki/WIKI.md`](../../../wiki/WIKI.md).

본 문서는 **상위 사양이 TC 로 빠짐없이 내려왔는지**를 확인하는 색인이다. 각 표의 마지막에 커버리지 수치를 적는다. TC 쪽 역방향 추적(어느 TC 가 무엇을 검증하는지)은 각 TC 의 첫 표가 갖는다.
