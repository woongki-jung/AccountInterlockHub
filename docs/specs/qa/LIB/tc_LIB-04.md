# 규약 테스트 벡터 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 규약 테스트 벡터가 **규약 대칭을 실제로 증명할 수 있는 형태**인지 확인한다. 벡터는 발송처의 자체 확인과 왕복(라이브러리 암호화 → 허브 복호화) 검증이 **같은 파일**을 근거로 삼게 하는 장치이므로, 형식·경계 커버리지·하네스 관측 계약이 모두 성립해야 한다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §프로그램 구성·기술스택·검증 방법 — "**규약 대칭(왕복) 검증**은 별도 통합 검증 항목으로 둔다 … 근거 데이터는 규약 적합성 테스트 벡터(`LIB-04`)다." · [`../../../prd/ia/IA.md`](../../../prd/ia/IA.md) `LIB-04`.
- **관련 IA 항목**: `LIB-04` (본 파일의 전 TC 공통)
- **검증 방법(qa 케이스)**: **CLI·배치** (C# 콘솔 호출 하네스). 왕복 대조 자체는 횡단 시나리오 `SCEN_007`·`SCEN_008` 이 담당하고, 본 파일은 **벡터와 하네스의 품질**을 검증한다.
- **공통 전제**: `ENV-LIB` 구성 · `SEED-VEC`(벡터 파일 `protocol-test-vectors.json`)
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-404.md`](../../processes/process_PROC-404.md) 의 라벨(`L1`~`L4` · `C1`·`C2`)을 인용한다.

### LIB-04_001 벡터 파일 형식 — JSON 1개·파일 수준 `hubBaseUrl`

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| DATA · Positive | SVC-009 · MDL-019 · 라이브러리 §규약 테스트 벡터 | PROC-404 | BR-024(선행) | 높음 | 자동 |

- **전제**: `SEED-VEC`
- **단계**: ① 패키지 안의 벡터가 **JSON 파일 1개**(`protocol-test-vectors.json`)인지 확인 `L3` ② 최상위 속성 확인 → `protocolVersion` · `hubBaseUrl` · `cases[]` ③ `hubBaseUrl` 이 **항목이 아니라 파일 수준 값**임을 확인(각 `cases[]` 항목에 중복되지 않는다) ④ 각 항목 구조 확인 → `caseId` · `boundaryNote` · `input{senderKey,birthDate,payload}` · `expected{encX,encY,requestUrl}` ⑤ 사람이 읽을 수 있고 기계가 파싱할 수 있음을 확인(표준 JSON 파서로 오류 없이 로드)
- **판정**: 공통 판정 기준

### LIB-04_004 벡터 1건 변조 → 불일치 검출·종료 코드 0 이외

| 계층·유형 | 검증 대상 | 검증 PROC | 검증 분기/예외 | 우선순위 | 자동화 |
|---|---|---|---|---|---|
| INTG · Negative | SVC-009 · 라이브러리 §검증 하네스 | PROC-404 | BR-024(불일치) | 높음 | 자동 |

- **전제**: `SEED-VEC` 사본에서 한 항목의 `expected.encX` 를 1문자 변조
- **단계**: ① 변조 벡터로 하네스 실행 `C1` → `failed = 1` · `failedCaseIds` 에 해당 `caseId` 가 담긴다 ② 종료 코드 → **0 이외** ③ 두 항목을 변조하면 `failed = 2` 이고 두 `caseId` 가 모두 담기는지 확인 ④ 절차 판정 → 불일치 시 **통합·배포를 진행하지 않고** 어긋난 항목으로 원인을 좁힌다
- **판정**: 공통 판정 기준

- **판정**: 공통 판정 기준
