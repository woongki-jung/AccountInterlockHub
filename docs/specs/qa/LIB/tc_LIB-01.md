# 데이터 암호화(연동 라이브러리) 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 발송처 프로세스 안에서 실행되는 라이브러리의 암호화가 **허브 복호화와 정확히 대칭**인지 확인한다. 규약이 한 자리라도 어긋나면 연동 자체가 성립하지 않으므로, 키 정규화 경계·IV 도출·`encY` 평문 구성·전달 인코딩을 값 단위로 대조한다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 3 — "발송처의 C# 프로젝트에서 호출하는 **.NET 클래스 라이브러리**로 **데이터 암호화**와 **연동 요청 URL 생성**을 제공한다." · §시스템 제약사항 — "**암호화·복호화 규약 대칭**: 연동 라이브러리가 암호화하고 허브가 복호화한다."
- **관련 IA 항목**: `LIB-01` (본 파일의 전 TC 공통)
- **검증 방법(qa 케이스)**: **CLI·배치** — C# 콘솔 호출 하네스가 라이브러리를 호출하고 결과를 **표준 출력 + 종료 코드**로 내보낸다([`../spec-qa.md`](../spec-qa.md) §테스트 환경 `ENV-LIB`)
- **공통 전제**: `ENV-LIB` 구성(라이브러리 빌드 산출물 + C# 콘솔 호출 하네스) · `SEED-VEC`(규약 테스트 벡터 파일)
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-401.md`](../../processes/process_PROC-401.md) 의 라벨(`C1`~`C3` · `L1`~`L8`)을 인용한다.
- **값 표기**: 규약 확정값(알고리즘·패딩·인코딩·상한)은 정책 [`policy_SEC-crypto.md`](../../policies/policy_SEC-crypto.md) §규약 확정값이 정본이며 본 문서는 참조만 한다.
