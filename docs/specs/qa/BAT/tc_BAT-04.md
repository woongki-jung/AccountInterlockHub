# 연동 추적 기록 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 연동 1건의 진행과 결과가 **추적 키 기준 단일 레코드 하나**에 모이는지, 결과 구분이 **레코드당 한 번만** 확정되고 이후 덮이지 않는지 확인한다. 이 노드는 화면·명령 표면이 없으므로 **API·서버 케이스로 백엔드와 함께** 검증하며, 관측은 기록 결과를 조회·조작하는 API 경로와 데이터베이스 직접 확인으로 한다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 9 — "연동 추적 키 기준 **단일 추적 레코드**를 사용자가 진입한 시점에 생성하고, 승인·거부·복호화 결과·수신처 전달 결과·결과 확인·완료 콜백을 같은 레코드에 이어 기록한다." · §프로그램 구성·기술스택·검증 방법 — "기록 기능(`BAT-04`·`BAT-05`·`BAT-06`)은 화면·명령 표면이 없어 **API·서버 케이스로 백엔드와 함께 검증**한다."
- **관련 IA 항목**: `BAT-04` (본 파일의 전 TC 공통)
- **검증 방법(qa 케이스)**: **API·서버** (관측 경로 = 사용자 진입 표면 3접점 · 서버 대면 API 3종 · `ENV-DB` 직접 조회)
- **공통 전제**: `ENV-API` 기동 · `ENV-DB` 시드 투입 완료 · `SEED-CONST-OK` 상수 주입 · `MOCK-RCV` 모의 수신처
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-301.md`](../../processes/process_PROC-301.md) 의 라벨(`C1`·`C2` · `B1`~`B7`)을 인용한다.
