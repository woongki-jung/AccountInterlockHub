# 보관정책 배치 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 보관 기간이 지난 기록이 **대상별 기준으로 정확히** 지워지는지, 배치가 **멱등**한지 확인한다. 이 기능은 인앱 스케줄 작업이라 명령으로 관측할 수 없으므로 **수동 실행 진입점**을 관측 지점으로 삼고, 표준 출력 요약 JSON 과 종료 코드로 판정한다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 9 — "일 단위 배치로 보관 기간 경과분을 삭제한다." · §프로그램 구성·기술스택·검증 방법 — "보관 배치는 인앱 스케줄 작업이라 명령 실행·종료 코드로 관측할 수 없으므로, **수동 실행 진입점 제공을 요구사항으로 둔다**(선택 사항이 아니다)."
- **관련 IA 항목**: `BAT-02` (본 파일의 전 TC 공통)
- **검증 방법(qa 케이스)**: **CLI·배치** — 실행 명령·인자·출력 스키마·종료 코드는 [`../../functions/spec-functions-api-server.md`](../../functions/spec-functions-api-server.md) §명령 진입점이 정본이다.
- **공통 전제**: `ENV-CLI` 구성(배포 산출물 기준 명령 실행) · `ENV-DB` 시드 투입 완료 · `SEED-CONST-OK` 상수 주입
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-304.md`](../../processes/process_PROC-304.md) 의 라벨(`C1`~`C3` · `B1`~`B7`)을 인용한다.
- **기간 값 표기**: `<RETENTION_MONTHS>`·`<RETENTION_MAX_MONTHS>`·`<CONSENT_PROOF_RETENTION_MONTHS>` 는 상수 주입값이며 본 문서는 수치를 복제하지 않는다. 시드의 일시는 **실행 시점 기준으로 상수 값을 적용해 산정**한다.
