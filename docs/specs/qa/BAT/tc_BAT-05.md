# 동의 증적 기록 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 사용자가 **어느 시점의 어떤 동의 항목에 동의했는지**가 개인정보 없이 사후 입증 가능한 형태로 남는지 확인한다. 동의 항목은 배포 상수라 시간이 지나면 내용이 바뀌므로 **버전 식별자와 그 시점 내용 스냅샷이 함께** 보존돼야 하고, 같은 식별자가 다른 내용을 가리키는 상태가 만들어지면 안 된다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 10 — "**동의 증적 기록**: 사용자가 어느 시점의 어떤 동의 항목에 동의했는지를 **개인정보 없이** 남긴다(추적 키·동의 시각·동의 항목 버전). 추적 레코드와 별도 보존 기간을 갖는다."
- **관련 법규**: 개인정보 보호법 제17조(개인정보의 제공) — 제3자 제공 시 동의 사실의 입증 수단이 본 엔터티다.
- **관련 IA 항목**: `BAT-05` (본 파일의 전 TC 공통)
- **검증 방법(qa 케이스)**: **API·서버** (관측 경로 = 동의·승인 제출 접점 · `ENV-DB` 직접 조회. 증적 조회 API 는 존재하지 않는다)
- **공통 전제**: `ENV-API` 기동 · `ENV-DB` 시드 투입 완료 · `SEED-CONST-OK` 상수 주입 · `MOCK-RCV` 모의 수신처
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-302.md`](../../processes/process_PROC-302.md) 의 라벨(`C1`·`C2` · `B1`~`B5`)과 [`../../processes/process_PROC-901.md`](../../processes/process_PROC-901.md) `B4` 를 인용한다.
