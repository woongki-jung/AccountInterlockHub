# 연동 지표 집계 테스트 케이스 정의

정본 목록은 [`../spec-qa.md`](../spec-qa.md). 용어는 [`../../../../wiki/WIKI.md`](../../../../wiki/WIKI.md).

## 개요

- **검증 목적**: 추적 레코드가 보관 기간이 지나 지워진 뒤에도 성과 지표를 낼 수 있도록 **카운터가 정확히 누적**되는지 확인한다. 성과 지표 **목표치의 달성 여부는 검증 대상이 아니다** — 목표치가 잠정값이고 확정 전까지 미달을 결함으로 다루지 않기 때문이다. 검증 대상은 **계수의 정확성**(요청 수 + 결과 구분 3종, 재진입 미계수 · 결과 미확정 종료의 미계수)이다.
- **관련 PRD 요구사항**: [`../../../prd/PRD.md`](../../../prd/PRD.md) §수행 범위 11 — "**연동 지표 집계**: 일자 단위 요청·성공·실패 건수만 누적한다. 추적 키를 포함하지 않아 개별 연동으로 환원되지 않으며 보관 기간 삭제의 영향을 받지 않는다." · §성과 지표 — "확정 전까지는 미달 자체를 결함으로 다루지 않는다(관측 대상일 뿐이다)."
- **관련 IA 항목**: `BAT-06` (본 파일의 전 TC 공통)
- **검증 방법(qa 케이스)**: **API·서버** (관측 경로 = 계수 계기를 만드는 접점 · `ENV-DB` 직접 조회)
- **공통 전제**: `ENV-API` 기동 · `ENV-DB` 시드 투입 완료 · `SEED-CONST-OK` 상수 주입 · `MOCK-RCV` 모의 수신처 · **각 TC 시작 시 당일 카운터 4종을 사전 기록**
- **공통 판정 기준**: **Pass** = 모든 단계의 기대 결과 일치 / **Fail** = 하나 이상 불일치(불일치 항목 기록) / **Block** = 전제 조건 미충족으로 실행 불가(사유 기록).
- **매핑 PROC 단계**: [`../../processes/process_PROC-303.md`](../../processes/process_PROC-303.md) 의 라벨(`C1`·`C2` · `B1`~`B5`)을 인용한다.
