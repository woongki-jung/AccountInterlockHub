# 용어사전 (WIKI)

AccountInterlockHub 산출 문서에 쓰이는 전문용어를 비개발자 기준으로 풀어 쓴다(정책 [`document-master-guide.md`](../ai/strategies/document-master-guide.md) §독자·표현). 전문용어를 쓰는 문서는 **서두에서 본 파일을 한 번 링크**한다(용어마다 링크를 반복하면 본문 가독성이 떨어진다).

## 연동 참여자

| 용어 | 뜻 |
| ---- | -- |
| **발송처** | 연동을 요청하는 쪽. 서비스 A 운용사다. 자기 회원 정보를 암호화해 허브로 사용자를 보낸다 |
| **수신처** | 연동을 받는 쪽. 서비스 B 운용사다. 허브가 전달한 값으로 회원을 확인해 자기 서비스에 연결한다 |
| **허브** | 이 제품(AccountInterlockHub). 발송처와 수신처 사이에서 사용자 동의를 받아 값을 중개한다 |
| **사용자** | 서비스 A의 고객. 연동 링크로 들어와 생년월일을 넣고 동의·승인 여부를 결정한다 |

## 데이터·암호

| 용어 | 뜻 |
| ---- | -- |
| **전달 데이터 (X)** | 발송처가 수신처에 넘기려는 값의 묶음. 수신처가 회원을 찾는 데 쓰는 키와 연동 추적 키를 담는다 |
| **발송처키** | 발송처만 아는 비밀 값. 전달 데이터를 잠그는 열쇠의 한쪽이며 허브는 갖지 않는다 |
| **encX** | 전달 데이터를 발송처키와 사용자 생년월일로 잠근 결과. 링크에 실려 허브로 온다 |
| **encY** | `encX`를 풀 열쇠를 사용자 생년월일로 다시 잠근 결과. 생년월일을 아는 사용자만 열 수 있다 |
| **IV (초기화 벡터)** | 같은 값을 잠글 때마다 결과가 달라지게 하는 보조 입력. 이 규약에서는 열쇠 값에서 잘라 쓴다 |
| **오프라인 전수대입** | 링크와 암호값을 확보한 사람이 자기 컴퓨터에서 생년월일을 하나씩 넣어 보며 값을 푸는 시도 |

## 추적·기록

| 용어 | 뜻 |
| ---- | -- |
| **연동 추적 키** | 연동 1건을 가리키는 이름표. 발송처가 만들어 전달 데이터에 담고, 나중에 이 이름표로 결과를 조회한다 |
| **연동 추적 레코드** | 연동 1건의 진행·결과를 담는 기록 1건. 사용자가 진입한 시점에 만들어진다 |
| **결과 확인** | 발송처가 처리상태 확인 API로 결과를 받아 간 것. 이 시점부터 보관 기간이 계산된다 |
| **결과 구분** | 결과가 어떤 이유로 그렇게 됐는지 나타내는 값(사용자 거부 · 복호화 실패 · 전달 실패 등) |
| **동의 증적** | 사용자가 언제 어떤 항목에 동의했는지 남기는 기록. 개인정보는 담지 않는다 |
| **지표 집계** | 개인정보 없이 날짜별 건수만 세어 두는 기록. 추적 레코드가 삭제된 뒤에도 사용량·성공률을 낼 수 있게 한다 |

## 프로그램·배포

| 용어 | 뜻 |
| ---- | -- |
| **연동 라이브러리** | 허브가 발송처에 주는 프로그램 조각. 발송처가 자기 프로그램에서 불러 암호값과 연동 요청 URL을 만든다 |
| **클래스 라이브러리 (.NET)** | 단독 실행이 아니라 **다른 프로그램이 불러 쓰는** 형태의 프로그램 파일. C# 프로젝트가 참조해 함수를 호출한다 |
| **.NET Framework 4.8** | 이 라이브러리가 동작하는 마이크로소프트 실행 환경의 버전. 발송처 서버에 기본 탑재된 세대다 |
| **호출 하네스** | 라이브러리를 검증하려고 만드는 작은 실행 프로그램. 함수를 불러 결과를 화면·종료 코드로 내보낸다 |
| **테스트 벡터** | "이 값을 넣으면 이 값이 나와야 한다"를 미리 정해 둔 대조표. 규약대로 만들었는지 서로 확인하는 기준이다 |
| **Azure App Service** | 마이크로소프트 클라우드에서 웹 애플리케이션을 실행해 주는 서비스. 이 제품은 여기에 하나로 배포된다 |
| **자가진단 API** | 발송처가 만든 암호값이 규약에 맞는지만 알려 주는 점검용 응답. 실제 연동·기록은 하지 않는다 |
