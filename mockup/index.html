AccountInterlockHub · 발송처 링크 진입부터 결과 확인까지, URL 하나 위에서 진행되는 네 단계입니다. 아래 카드 순서가 곧 진행 순서이며, 각 화면 파일은 사양의 화면 상태를 상단 도구모음에서 토글로 시연합니다.

화면별 URL 이 없습니다. 네 화면은 사양상 <INTERLOCK_ENTRY_PATH> 라는 같은 경로 위의 네 단계이며, 실제 제품에서는 서버 응답이 같은 문서 안의 내용만 바꿔 화면을 전환합니다(리다이렉트 없음). 이 목업에서는 담당자가 각 단계를 독립적으로 열람·검토할 수 있도록 화면마다 별도 파일로 나누었습니다 — 파일 분리는 목업 전용 편의이며 제품의 URL 구조가 아닙니다.

각 화면 상단의 어두운 막대(노란 테두리)는 목업 전용 도구입니다 — 화면 이동 내비게이션과 상태 전환 버튼이며, 실제 제품에는 존재하지 않습니다(이 제품에는 전역 네비게이션·로그인이 없습니다). 카드 안쪽 흰 영역만 실제 화면 사양입니다.

모든 파일은 외부 자원(CDN·웹폰트·이미지) 없이 동작합니다. 인터넷 연결 없이 브라우저로 직접 열어 확인할 수 있습니다.
