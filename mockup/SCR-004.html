경로 ②(링크·복호화 오류)는 확정 결과 재안내 대상이 아닙니다 — 추적 키를 확보하기 전에 항상 실패가 확정돼 레코드가 만들어지지 않습니다(EXC-BIZ-14, screen_SCR-004.md §확정 결과 재안내: 배지가 붙는 경로는 ①·③뿐). 위 재안내 체크박스가 비활성화됩니다.

returnUrl 토글은 경로 번호와 별개로 복귀 영역 표시를 켜고 끕니다 — 표시 조건이 경로 번호가 아니라 이 필드의 존재 여부임을 보이기 위한 것으로, 실제로 값이 실리는 경로는 ① 하나뿐이라 경로 ②·③ 으로 바꾸면 기본으로 꺼집니다(거기서 직접 켜 보는 것은 목업 시연 전용이며 실제로 일어나지 않는 조합입니다). 외부 이동 토글이 꺼져 있으면(기본값) 대기 종료·수동 링크 클릭 시 실제로 이동하지 않고 "이동했습니다"로 대체합니다 — 이동 대상은 잠정 상수 · 실제 값은 CLAUDE.env.md(<COMPLETION_REDIRECT_URL>, 현재 개발용 더미 https://www.naver.com)입니다.

사양 §화면 간 이동 경로 요약 (목업 보조 — 제품 UI 아님)

  • 복귀 주소(허브 밖·여정의 끝) — 복귀 이동 대기 시간 경과 또는 "지금 돌아가기" 클릭 시 이동. returnUrl 이 있고 절대 URL 확인을 통과할 때만(실제로 실리는 경로는 ① 하나)
  • returnUrl 이 없거나 확인 미달이면(경로 ②·③ 포함) 화면이 제공하는 이동 수단이 없습니다 — 잔류
  • 새로고침·같은 링크 재진입 → SCR-001 본인확인부터 다시 시작(진입 판정 통과 시)
  • 결과가 확정된 추적 키로 재진입하면 본인확인 통과 후 이 화면(경로 ①·③ 은 확정 결과 재안내)으로 돌아옵니다
  • 진입 단계 실패(경로 ②)는 추적 레코드가 없어 재진입해도 같은 판정으로 다시 경로 ②가 됩니다
