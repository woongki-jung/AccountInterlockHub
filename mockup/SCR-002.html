허브 ① SCR-001 본인확인 ② SCR-002 동의·승인 ③ SCR-003 진행 안내 ④ SCR-004 결과 안내
상태 전환:

사양: screen_SCR-002.md §화면 상태 전이 · §조건부 표시. 거부·취소 종료 수단은 없습니다 — 동의하지 않는 사용자의 종료 수단은 창을 닫는 것입니다(BIZ-003-03). "유효성 안내"는 미동의 상태에서 버튼을 눌렀을 때 화면이 막는 1차 방어(문구: "모든 항목에 동의해 주셔야 합니다"), "서버 EX-BIZ-001"은 서버 재검증 실패(문구: "필수 동의 항목에 모두 동의해 주세요.") — 문구가 서로 다릅니다. 체크박스를 직접 눌러도 버튼 활성 여부가 즉시 반영됩니다.

연동 동의

아래 내용을 확인하고 모든 항목에 동의해 주세요.

아래 항목에 동의하시면 서비스 연동이 진행됩니다. 동의하지 않으시면 연동이 취소됩니다.

사양 §화면 간 이동 경로 요약 (목업 보조 — 제품 UI 아님)

  • 승인 버튼 클릭(필수 동의 충족) → SCR-003 연동 진행 안내
  • 승인 제출 응답이 확정 결과 재안내 또는 EX-SEC-001·EX-SEC-002 → SCR-004 결과 안내
  • 승인 시점 재복호화 실패(EX-AUTH-001·EX-AUTH-002) → SCR-001 본인확인(재입력)
  • 필수 미충족 상태에서 승인 버튼 클릭(aria-disabled) → 이 화면 유지 — 요청을 보내지 않고 유효성 안내만 띄운다
  • 서버 재검증 실패(EX-BIZ-001)·처리 오류(EX-BIZ-003) → 이 화면 유지(위 상태 전환 참고)
