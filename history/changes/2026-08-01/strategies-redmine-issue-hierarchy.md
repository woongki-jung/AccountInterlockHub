# strategies-redmine-issue-hierarchy (2026-08-01)

> 모든 산출 일감을 **작업세션 이슈를 뿌리로 하는 단일 트리**에 매도록 계층 규칙을 강제로 전환했다. 종전에는 부모 지정이 허용 표현("묶을 수 있다")에 그치고 트리 최상단인 그룹 일감의 부모가 아예 미규정이라, directing·spec·build·qa 산출 일감이 프로젝트 루트에 흩어져 생성됐다. 담당자 지시·결정 4건 2026-08-01.

- **무엇**: 이슈 계층 규칙의 강제화와 그 배선.
  - **루트는 작업세션 이슈뿐** — `작업세션 → 그룹 → 사양·기능·오류·목업 → 검증` 4단계 트리를 `work-tracking.md` §계층·연관에 그림과 함께 정본으로 두고, **프로젝트 루트에 일감을 만들지 않는다**를 원칙으로 명시했다. 그룹 일감이 없는 작업(directing·운영/메타)은 작업세션 직속이다.
  - **`parent_issue_id` 필수화** — 생성 시 선택 항목이던 부모 지정을 필수로 올리고, **생성 직후 `GET` 으로 `parent` 실측 확인**을 의무화했다. 부모를 빠뜨려도 Redmine 은 오류 없이 루트 일감을 만들어 응답만으로는 누락을 알 수 없다 — 이 함정을 `work-tracking-redmine.md` §도구 함정에 등재하고 PUT 교정 방법을 함께 적었다.
  - **부모 좌표 전달을 디스패치 계약에 명시** — 서브에이전트가 일감을 만들려면 부모 번호를 알아야 하므로, ai-pm→product-loop→단계 오케스트레이터로 **작업세션 이슈 번호·그룹 일감 번호가 흘러가도록** 각 에이전트의 §입력을 필수 항목으로 고쳤다. product-loop 는 그룹 일감 생성 시 부모를 작업세션으로 지정한다.
  - **`오류` 일감의 부모 신설** — 종전에는 연관만 규정돼 루트로 떨어졌다. **그룹 하위**(없으면 작업세션 직속)로 두고 검증·사양 일감은 연관으로 단다. 검증 일감 아래로 매달지 않은 것은 계층이 5단계가 되면 닫기 사슬만 길어지기 때문이다.
  - **계층과 연관의 역할 분리를 명문화** — 계층은 "어느 업무에 속하는가", 연관(relations)은 "무엇을 근거로 삼는가". 종전 문서가 둘을 "연관/하위" 로 뭉뚱그려 서술해 구현이 갈렸다.
  - **작업세션 종결 규칙 신설**(`work-tracking.md` §작업세션 종결) — 계층화의 직접 부작용에 대한 대응이다. 작업세션이 트리 루트가 되면서 **열린 하위가 하나라도 있으면 닫히지 않는데**, 정책상 열린 채 남는 것이 정상인 일감이 넷 있다(🔵🟣 잠정 Pass 검증 · 🟠 Block·이월 · 미해소 `오류` · 잔여 확인 항목이 있는 기능). 이 경우 **작업세션을 `해결` 로 두고 닫지 않으며**, 닫으려고 하위를 임의 종결하거나 부모에서 떼어내지 않는다(잔여를 감추는 행위). 회신 노트에 열린 하위를 번호·상태·사유로 나열해 담당자가 무엇을 기다리는지 보이게 한다. 세션 report 는 실제로 종결하는 사이클에만 남긴다.
  - **ai-pm 의 이슈 생성 금지를 작업세션 트래커로 한정** — 종전 "봇은 이슈를 생성하지 않는다"는 전면 금지였는데, 이 원칙과 "directing 산출을 Redmine 일감으로 추적한다"가 충돌해 directing 일감이 실제로는 생기지 않았다. 금지의 취지는 **대화 스레드를 여는 것은 사람 몫**이라는 데 있으므로 그 범위를 작업세션 트래커에만 적용하고, directing 산출 일감은 ai-pm 이 **작업세션 직속 하위로** 만들도록 허용했다.
- **왜**: 담당자가 작업세션 이슈로 요청하면 그로부터 파생된 일감들이 프로젝트 루트에 평평하게 쌓여, 어느 일감이 어느 업무에 속하는지 이슈 목록에서 분간되지 않았다. 원인은 셋이었다 — ① 그룹 일감(트리 최상단)의 부모가 어디에도 규정되지 않음 ② 사양·기능의 부모 지정이 "묶을 수 있다"는 허용 표현 ③ 생성 API 규약에서 `parent_issue_id` 가 괄호 주석 수준의 선택 항목이고 생성 후 실측 대상에서도 빠짐. 부모가 강제된 것은 검증 일감과 report 일감 둘뿐이었다.
